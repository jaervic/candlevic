Un <Term term="Drawdown">drawdown</Term> es la caída desde el máximo de tu cuenta hasta el mínimo posterior. No mide una operación: mide el dolor acumulado. Y el dolor cambia la forma en que decides.

<DatasetChart dataset="btc-bear-2022" from={150} to={426} height={220} showVolume caption="BTC en 2022: más de un año de caída. El problema no fue solo el precio, sino las decisiones que tomó la gente por dentro." />

## La asimetría que lo cambia todo

| Si caes… | Necesitas ganar… |
|---|---|
| −10 % | +11,1 % |
| −25 % | +33,3 % |
| −50 % | +100 % |
| −75 % | +300 % |

Cuanto más grande es la caída, más desproporcionado es el esfuerzo para recuperarla. Por eso el objetivo principal no es ganar mucho: es **no perder demasiado**.

## Las etapas del drawdown

1. **Negación.** "Es una corrección, volverá".
2. **Culpa.** "Debí vender antes".
3. **Improvisación.** Aumentar el tamaño para recuperar.
4. **Agotamiento.** Operar sin ganas o dejar de mirar.
5. **Aceptación.** Reducir tamaño, revisar el sistema y volver con reglas.

<Callout type="warning" title="La trampa del doble o nada">
Después de una caída, el impulso de duplicar el tamaño para recuperar es el atajo más rápido a una caída mayor. El tamaño se reduce, no se aumenta.
</Callout>

<KeyIdea>
En un drawdown, la prioridad no es recuperar rápido: es dejar de hacer daño. Reducir tamaño, parar y revisar es parte de la estrategia.
</KeyIdea>
